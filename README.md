- **Hansel** — multimodal AI bot. Multi-API routing, image analysis, voice recognition, Solana trading. Custom React frontend. Runs on a Pi.
- **Private AI Node** — custom-built advanced AI system running 24/7 on a private server. Multi-model architecture, always online, always listening. Not on GitHub. Not for sale.

**🔐 Cryptography & Privacy Engineering**
- **XMTP Integration — Core Specialism.** I don't just use XMTP — I embed it deep. Custom-coded E2EE messaging layers across multiple projects: real-time encrypted chat in Oden Network XR, wallet-to-wallet direct messaging, encrypted notification pipelines, and private social primitives built on the XMTP protocol stack. If it touches a message, it's encrypted by default.
- **ZK-Proof Systems** — implemented zero-knowledge proof architecture for anonymous interactions. Users prove membership, eligibility, or identity without revealing anything. Privacy by mathematics, not policy.
- **Semaphore Protocol** — deployed Semaphore for ZK anonymous posting in Oden Network XR. Groth16 proof generation, on-chain verification, identity commitments. Users post without a trace.
- **Security & Data Frameworks** — custom frameworks for data analysis tooling and security modelling. Threat pattern analysis, encrypted data pipelines, access control systems built from scratch.

**📈 Crypto, Quant & Finance**
- **Blockchain Rewards Ecosystem** — designed and coded a fully functioning on-chain rewards system for a live dapp. Custom smart contracts, token distribution logic, staking mechanics, and user-facing rewards dashboard. End-to-end — from Solidity to frontend. Solo.
- **Solana Trading Bot** — live, profitable, autonomous. Custom-built scalping system with real execution on Solana mainnet. RSI/MACD/BB signal stack, momentum strategies, dip-buying logic, risk management. Not a demo. Runs real money.
- **AI Crypto Quant Bot** — PyTorch price forecasting, backtester with equity curves + Sharpe ratio. No API key required.
- **Financial & Investment Tooling** — personal suite of financial analysis tools: portfolio tracking, P&L dashboards, quant signal engines, market data pipelines. Built for real decision-making, not paper trading.
- **Oden Network XR** — E2EE messaging via XMTP, ZK anonymous posting via Semaphore/Groth16, direct ETH tipping. Solo-built on Base L2.
